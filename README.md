🌤️ Weather App

A simple and responsive weather application built using HTML, CSS, and JavaScript. The application uses the OpenWeatherMap API to display real-time weather information for a city.

🚀 Features

Search weather by city name

Displays current temperature

Shows weather condition

Displays "feels like" temperature

Displays humidity

Displays wind speed

Responsive design

Error handling for invalid city names

🛠️ Technologies Used

HTML5

CSS3

JavaScript

OpenWeatherMap API

⚙️ How to Run

Clone this repository:

git clone https://github.com/YOUR-USERNAME/weather-app.git


Open the project folder.

Get an API key from OpenWeatherMap.

Add your API key in script.js:

const API_KEY = "YOUR_API_KEY";


Open index.html in your browser.

🔑 API

This project uses the OpenWeatherMap Current Weather API.
